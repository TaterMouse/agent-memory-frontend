# 智能体记忆系统前端

面向学校实训项目的前端协作骨架，基于 `React + Vite + TypeScript + Ant Design`。

## 技术栈

- React 19
- Vite
- TypeScript
- React Router
- Axios
- Zustand
- Ant Design

## 启动方式

```bash
pnpm install
pnpm dev
```

## 目录说明

- `src/api`：接口封装与类型定义
- `src/pages`：页面模块
- `src/components`：通用组件与业务组件
- `src/store`：全局状态
- `src/router`：路由配置
- `src/utils`：工具函数
- `src/constants`：常量与枚举

## 分支建议

- `main`：稳定可展示版本
- `dev`：团队日常开发分支
- `feature/*`：个人功能分支
